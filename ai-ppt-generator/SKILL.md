# AI PPT生成
使用用户输入的主题/查询，通过百度AI的流式API生成高质量PPT下载链接。

## 重要：流式超时行为
此技能使用**流式HTTP请求**，可能需要**2分钟以上**才能完成。OpenClaw的默认超时设置可能会在完成前中断流。

为确保成功生成：
1. **代理必须等待完整的流**，直到收到 `is_end: true`
2. **不要依赖立即完成**——监控流式响应
3. **如果发生超时**，即使生成在服务器端继续，技能也会显示为失败

## 工作流程
1. 使用用户查询执行 `scripts/generate_ppt.py`
2. **等待流式完成**（通常需要2分钟以上）
3. 当收到 `is_end: true` 时返回最终的PPT URL

### 预期输出格式
成功完成返回：
```json
{
  "status": "PPT导出结束",
  "show_msg": "PPT导出成功",
  "is_end": true,
  "data": {
    "ppt_url": "https://...ppt"
  }
}
```

在生成过程中，您会看到临时的 `{"status": "..."}` 消息。

### 使用示例
```bash
python3 scripts/generate_ppt.py --query "经济总结报告ppt"
```
**注意query中文字内容不要有空格或特殊字符**

## 代理指令
使用此技能时：
- **设置适当的超时时间**：确保exec/sessions有足够的超时时间（180秒以上）
- **监控流式输出**：如果初始响应仅显示状态，不要假设失败
- **等待完成**：最终URL仅在流结束时出现，并带有 `is_end: true`
- **优雅处理**：如果被中断，通知用户生成可能在服务器端继续

## 故障排除
- **PPT未出现**：可能是流完成前的超时
- **仅显示状态消息**：生成正在进行中，等待更长时间
- **脚本提前退出**：检查 BAIDU_API_KEY 和网络连接
