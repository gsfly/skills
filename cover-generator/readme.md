\## 设置

1\. \*\*注册火山引擎账号\*\*：

&nbsp;  - 访问 \[火山引擎官网](https://www.volcengine.com/) 注册账号

&nbsp;  - 开通即梦AI服务，选择免费试用

&nbsp;  - 创建API访问密钥（Access Key和Secret Key）



2\. 安装依赖：

&nbsp;  ```bash

&nbsp;  pip install -r requirements.txt

&nbsp;  ```



3\. 设置火山引擎API密钥：

&nbsp;    在技能目录下创建 .env 文件，添加以下内容：

&nbsp;    ```

&nbsp;    VOLCENGINE\_ACCESS\_KEY=你的Access Key

&nbsp;    VOLCENGINE\_SECRET\_KEY=你的Secret Key

&nbsp;    ```
